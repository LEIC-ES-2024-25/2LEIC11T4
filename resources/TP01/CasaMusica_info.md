# UML Casa da Música:
## Responsável instalações:
- registo salas
- divisão setores
- lugares numerados
	
## Responsável programação cultural:
- prog. cultural (espetáculos)
- nome espetáculo
- descrição
- sala
- dia e hora
- duração
- artistas:
	- nome
	- nacionalidade
	- biografia
- preço
- data-hora limite
- estatistica afluência público
- receitas espetáculo

## Público geral:
- consulta prog. cultural
- cliente registados:
	- nome 
	- nacionalidade
	- morada
	- mail
	- reserva bilhetes: 
		- id cliente
		- espetáculo
		- setor
		- nº lugares
		- preço
	- id reserva
	- data-hora limite
		
## Empregados caixa:
- venda bilhetes c/ ou s/ reserva
